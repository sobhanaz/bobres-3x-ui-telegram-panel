# لایسنس

[فهرست راهنما](FA-Home) · [داشبورد](FA-Dashboard) · [نمایندگان](FA-Resellers)

مدل BOBRES **هستهٔ رایگان، امکانات پولی** است. بدون هیچ لایسنسی می‌توانید یک فروشگاه را برای همیشه اجرا کنید. لایسنس امکانات بیشتری باز می‌کند: سرور و سرویس و کارمند بیشتر، نمایندگان، تتر خودکار و برداشتن «Powered by BOBRES». هر لایسنس برای **یک نصب** و یک دامنه است.

## دورهٔ آزمایشی ۳۰ روزه

هر نصب، تازه یا به‌روزشده، **۳۰ روز** از اولین اجرای نسخه‌ای که این سیاست را دارد، همهٔ امکانات به‌جز برداشتن «Powered by BOBRES» را دارد. نیازی به درخواست یا ثبت‌نام نیست و به شخص یا حساب بسته نیست. وقتی تمام شد، چیزی پاک یا خاموش نمی‌شود و فقط محدودیت‌های سطح رایگان روی کارهای **تازه** اعمال می‌شود. داشبورد در نوار بالا روزهای باقی‌مانده را نشان می‌دهد و هفتهٔ آخر هشدار می‌دهد.

## فعال‌سازی

۱. لایسنس را از فروشنده می‌خرید و یک **کلید لایسنس** (`BOBRES-...`) می‌گیرید. کلید فقط یک بار نشان داده می‌شود. نشانی سرور لایسنس را هم فروشنده می‌دهد.

۲. نشانی را روی سرور بگذارید (فقط https پذیرفته می‌شود):

<div dir="ltr">

```bash
sudo bobres config set BOBRES_LICENSE_SERVER https://license.example.com
```

</div>

۳. کلید را فعال کنید. دستور کلید را مخفی می‌پرسد:

<div dir="ltr">

```bash
sudo bobres license activate
```

</div>

اگر کلید در فایل است: `sudo bobres license activate < key.txt` و فایل را بعد پاک کنید. کلید را روی خط فرمان ننویسید، چون در تاریخچهٔ شل می‌ماند. راه دیگر: داشبورد ← **سیستم** ← **لایسنس** ← «فعال‌سازی با کلید لایسنس».

۴. وضعیت را ببینید:

<div dir="ltr">

```bash
sudo bobres license status
```

</div>

از این پس هستهٔ برنامه هر روز لایسنس را خودکار تمدید می‌کند. توکن لایسنس حداکثر ۳۰ روز اعتبار دارد و به دامنه و نصب شما بسته است. اگر فروشنده توکن را مستقیم داد، `sudo bobres license import < token.txt` یا چسباندن در همان زبانهٔ لایسنس کار می‌کند.

لایسنس را می‌شود تا ۳ بار در سال به سرور یا دامنهٔ دیگر برد. بازیابی پشتیبان روی سرور تازه با همان دامنه حساب نمی‌شود، چون شناسهٔ نصب همراه پشتیبان می‌آید.

مشکل‌های رایج فعال‌سازی (`invalid_key`، `reactivation_limit`، «سرور لایسنس جواب نداد»): [runbook لایسنس](https://github.com/sobhanaz/bobres-3x-ui-telegram-panel/blob/main/docs/runbooks/license.md).

## وقتی اشتراک تمام می‌شود

1. اگر تمدید نکنید، لایسنس تا پایان دورهٔ پرداخت‌شده کار می‌کند.
2. بعد یک **مهلت** (پیش‌فرض ۱۴ روز) می‌آید. همه‌چیز کار می‌کند و داشبورد هشدار می‌دهد.
3. بعد از مهلت، نصب به **سطح رایگان** برمی‌گردد (یا به دورهٔ آزمایشی، اگر هنوز مانده باشد). «Powered by BOBRES» برمی‌گردد.

**هیچ‌چیز پاک نمی‌شود.** داده‌ها، سرویس‌های مشتری‌ها، سرورها، کارکنان و تنظیمات سر جایشان می‌مانند. سرویس‌های موجود حتی بالاتر از سقف رایگان کار، تمدید و شارژ می‌شوند. فقط کارهای **تازهٔ** بیش از سطح رایگان رد می‌شوند، تا تمدید:

- خرید یا تست رایگان تازه، وقتی مشتری‌ها ۲۵ سرویس فعال دارند. مشتری فقط می‌بیند «خرید جدید موقتاً در دسترس نیست. لطفاً با پشتیبانی تماس بگیرید.» و چیزی دربارهٔ لایسنس نمی‌شنود؛ شما روزی یک بار هشدار می‌گیرید.
- سرور دوم، نمایندهٔ تازه، تتر خودکار و کارمند بیش از صندلی‌ها. نمایندگان فعلی حساب و آنچه خریده‌اند را نگه می‌دارند.
- کانال اجباری دوم. کانال‌های ذخیره‌شده می‌مانند ولی فقط اولی اجرا می‌شود و بقیه «غیرفعال: نیاز به Pro» نشان داده می‌شوند.

با تمدید، امکانات در تمدید روزانهٔ بعدی برمی‌گردند. چیزی دوباره نصب نمی‌شود.

## حریم خصوصی

اطلاعات مشتری‌های شما هیچ‌وقت به فروشنده نمی‌رود. فعال‌سازی کلید، شناسهٔ نصب، دامنه و نسخه را می‌فرستد؛ تمدید روزانه توکن نصب‌شده و نسخه را. هر دو فقط وقتی انجام می‌شوند که فعال‌سازی آنلاین را روشن کرده باشید (`BOBRES_LICENSE_SERVER`)، و سرور لایسنس نشانی IP درخواست را می‌بیند.
